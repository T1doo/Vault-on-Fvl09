# F3 首次真正 lift：承重后滚转失稳

来源：`Robotwin2/datasets/p48_f3_micro_001`，CPU-only、没有修改原 artifact 或任何 Gate/物理参数。`analysis.json` receipt `dd1e420cd77cf23b02522860c94dd2ff75af11605f2e0d686618ccf903476a6e`。

## 证据结论

此次不是抓空、规划失败或夹爪突然松开。机器人确实完成 lift；双指一直有物理接触，但瓶子在失去 pad 支持后绕两指之间的近似横向接触线持续滚转。接触存在不等于刚性抓稳。瓶子 actor 原点位于接近端部，滚转又放大了该点相对 EEF 的位移和升高不足；不能把全部 13.7mm 漂移描述成瓶子竖直从两指间滑下。

| trace row | lift 后时间 | 事实 |
|---|---:|---|
| 1413 | 0 | 实际 postclose 基准；指7/8 qpos 31.586/30.947mm，命令均17.5mm |
| 1418 | 20ms | 首个没有瓶-pad物理支持的记录 |
| 1434 | 84ms | 相对平移首次超过1mm（描述性定位，不是新Gate） |
| 1473 | 240ms | 角漂移0.05034rad先违反原0.05rad Gate；平移4.691mm |
| 1477 | 256ms | 平移首次超过原5mm Gate |
| 1524 | 444ms | lift执行结束；actor升高13.726mm，EEF升高22.567mm |
| 1574 | 644ms | 确认窗末 actor升高10.917mm；相对漂移13.701mm/0.148625rad |

末帧 EEF 升高23.420mm；瓶体包围盒几何中心升高约27.997mm，actor原点仅10.917mm。这种分化与滚转一致，不能把几何中心或未记录的 COM 换入旧成功判据。

双指接触点主要位于 bottle-local y≈0.0973m 的同一截面、x≈±0.032m；开度没有扩大，末帧指7/8 qpos反而降至31.535/30.599mm。每指逐步 impulse norm sum 始终约0.05–0.055，后续没有双指同时失载的突变。指7接触从两点减到一点，末帧局部 y 移到0.093916m，指8仍约0.097509m；支持“承重后转动/接触局部滑移”而不是完整脱手。

两指法向主要沿相反 world x，但还有共同的倾斜分量；末帧约 `[0.993,0.001,-0.117]` / `[-0.989,-0.076,-0.128]`。这不是充分的抗转矩夹持证明。原始 point impulse vector、normal、位置和 separation 已逐帧保存，未确认 SAPIEN body-order 符号约定前不把向量符号解释成瓶子净受力。impulse norm 也不是抓取法向力，不能直接按两个范数判断摩擦余量。

## 只建议一个修订：沿瓶轴前移抓取 station 约13.1mm

七个实际 native 凸包的等密度体积加权中心为 actor-local `[0.00003117,0.11045115,0.00001300]m`。当前抓取截面约 y=0.09735m，比该代理中心偏后约13.1mm；瓶体长轴沿 local y，模型整体范围 y=[0,0.247888]m。这个力臂和离台后持续滚转相符，因此优先将**同一个 r3063 的抓取 station 沿瓶轴前移13.1mm**，保持 top-down 朝向、抓取深度、pregrasp间距、close0.50、hold250、lift25、运动速度和所有物理参数不变。不再增加其他候选或同时改速度。

这是几何代理驱动的一项建议，尚未 CPU 几何通过、IK 通过或物理通过。真实 PhysX `cmass_local_pose` 未记录；凸包加权中心可能受重叠质量计算或显式质量/惯性配置影响，不可伪称真实 COM。下一已授权 fresh scene 应记录该刚体实际 COM/惯性，而不是增加独立探针场景。若实际 COM 与建议依据明显矛盾，应在动作前停并重新审查，不能悄悄换成另一个点。
