# Native F4 entry and qualification producer

`native_f4.run_native_root(spec, output, authorization)` binds explicit resolved roles/cameras to a new native scene context, then reuses the original qualified full-program planner and executor. The previous adapter constructor rebuilt an old fixed-layout candidate from its ID; this new version initializes its lower-level adapter and validates external scene-bound qualification instead. The old runtime/source snapshots remain untouched.

`native_f4_qualification.run_native_qualification(spec, output, authorization)` is the actual qualification producer. It requires an expected hash for the source profile, preserves that profile's grasp policy/arm/size, recomputes source and slot candidates against the new scene, and calls the native pure-CPU geometry validator. It then schedules three real planner scene bodies followed by A_ONLY/B_ONLY/C_ONLY/AB_NONINTERFERENCE/AC_NONINTERFERENCE physical scene bodies. It captures original current/anchor before action, preserves actual trace/terminal/cleanup records, and emits exact source-planner-terminal and isolation bindings for the three full-program specs. No real qualifier has been run in this CPU Goal.

The old micro/full-spec builder's single fixed-runtime-scene expression is replaced in an isolated AST copy by the explicit scene spec. Its synthetic-stage-A argument is therefore never evaluated. All other original terminal, program and candidate validations remain in that builder. There is no default terminal or implicit success.

Collection is 3 programs × 3 real realizations. r_inv_path changes the three native carry_mid transport waypoints, preserving grip/release/neutral poses and execution arm. r_inv_motion adds a recorded post-prefix hold. The underlying source planner/executor records new real setpoints; no old trajectory is copied to count as a realization. Only r_pc is required to have strict shared prefix. Generic root structural checks compare actual current/anchor and arrays, and F4 additionally reads source-bound trace to compare both EEFs, robot joints/speed/gripper, all relevant object final poses, non-task drift and role terminal speed across all nine cells.

A finite second cohort attempt uses the isolated recoverable orchestrator. Existing accepted cells are referenced and validated, with original prefix comparison; completed cells are not physically re-executed. Different source/spec refuses recovery; unresolved owned cleanup and missing recovery authorization block a failed attempt.

Actual call accounting before recovery: each cohort has one pristine scene, three task-feasibility scenes, one canonical-prefix execution, three suffix-preflight executions, and three collection executions. Thus root base is 33 fresh / 21 action / 9 collection. Planner ceiling is 3 × (24 prefix + 3 × 42 suffix) = 450 queries. Qualification adds 8 fresh / 5 action / 0 collection, with ceiling 3 × 42 + 3 × (24 + 22) + 2 × (24 + 32) = 376 queries. The 24 prefix allowance is a limit, not measured consumption. Recovery and GPU leases are additional frozen-budget items; no GPU seconds are inferred from CPU tests.

Validation: ten CPU tests verify explicit actor roles, source geometry recomputation for the first two actual planned F4 layouts, no default qualification, authorization before native imports, bounded real path targets, query accounting categories, and isolation of the old fixed scene expression. No GPU, planner or physical scene execution occurred. Newly generated scenes still need the authorized native qualification and collection gates. The entry does not claim old pilot data are formal/untouched test data.

Whole-pipeline fixture validation adds two tests (12 total F4 tests): actual family dispatch and recoverable native orchestration produce nine explicitly synthetic cells, followed by the real independent F4 disk/terminal verifiers and generic source sealing/copy/root reader. A branch interruption stops later cohorts; the second attempt preserves the accepted cell and executes missing cells only. The packaged nine-cell root is read using its bundled reader with original root/export/intermediate-cell paths denied. These fixture successes never set native physical evidence or research eligibility.
