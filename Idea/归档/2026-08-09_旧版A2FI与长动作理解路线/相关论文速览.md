## 1. 八篇核心前置论文（师哥清单）

### π0.5 — backbone（PI 公司，arXiv:2504.16054）
- **是什么**：开放世界泛化的分层 VLA。同一模型先预测语义子任务 ĥ 再出动作，π(a,ĥ|o,ℓ)=π(a|o,ĥ)·π(ĥ|o,ℓ)；异构 co-training（97.6% 数据非目标任务）；预训练 FAST 离散 token + 后训练 flow-matching action expert；能在全新家庭做 10–15 分钟长时程任务。
- **对 idea**：①宿主：它是"观测→意图→动作"**正向**通路，我们补**反向**"(观测,动作)→意图"；② *implicit-HL* 消融（只把子任务预测数据混进训练就拿到大部分收益）是"理解目标反哺控制"假设的最强背书；③注意力信息流严格单向 VLM→action expert，反向通路默认是断的；④**工程警告**：官方 openpi 当前只支持 flow head，论文里的 FAST 通道不可直接复用——需另建 observed-action encoder；LoRA 微调 >22.5GB 显存、全量 >70GB。

### π0 — backbone 地基（PI 公司，arXiv:2410.24164）
- **是什么**：首个 flow-matching VLA。PaliGemma 3B + 300M action expert（独立权重、仅经注意力交互），50Hz 连续动作块，1 万小时 7 本体预训练，确立"预训练→后训练"配方。
- **对 idea**：action expert / flow matching / 分块因果 mask 的完整机制说明书。flow 分支被严格隔离——反向理解头绝不能碰 flow，应走文本侧另设交叉熵头；π0 只有 flow 通道正是选 π0.5 的理由（后者理论上有文字化动作表示）。

### VLA-JEPA — 方法+写作参考（USTC 等，arXiv:2602.10098）
- **是什么**：批判"从视频学 latent action 学歪了"（锁死像素变化 + 信息泄漏）。JEPA 式**无泄漏状态预测**：未来帧只当监督（冻结 V-JEPA2 target encoder）绝不进输入，在隐空间预测未来状态。LIBERO 97.2、LIBERO-Plus 鲁棒性大幅领先。
- **对 idea**：① **leakage-free 是做 A2FI 的必守护栏**（意图/未来只能当 target，防模型抄捷径）；②真机自曝"指令细粒度理解不足、易抓错物体"——"物理稳 ≠ 语义懂"的独立实验证据，动机神助攻；③写作骨架（失败模式→单一病根→一条原则）可套用。

### RoboTwin 2.0 — 数据工厂+考场（SJTU/HKU 等，arXiv:2506.18088）
- **是什么**：MLLM 闭环代码生成 + 5 维强域随机化的双臂数据生成器与 benchmark；731 物体 / 50 任务 / 5 本体 / 10 万+轨迹。核心发现：干净仿真数据几乎不提升鲁棒性，域随机化数据才有用。
- **对 idea**：四块免费拼图——`step_name` 原子切分、仿真真值算累计 delta、成对多样指令、Hard 设置当反捷径评测。**坑**：`step_name` 是动作描述级（≈LACY 层级，意图级标签要自造）；⚠️ 本地实测（2026-07-26，commit c3ddfa8b 自采数据）：**采集管线的 HDF5 不含 `step_name`/逐帧语义标签**，事件边界须另取（`_traj_data` 规划段 / 夹爪-接触事件 / 源码插桩），详见 [idea主干](idea主干-动作序列的功能性意图理解.md) §5.3；VLM 观察者 F1≈0.30 不可信，成功判定用仿真真值。
- 备注：我们工作区 `Robotwin2/` 已在 fvl09 上配好其官方环境并打通数据采集（见 `../Robotwin2环境配置/`）。

### LIBERO — 数据+评测（UT Austin 等，NeurIPS'23，arXiv:2306.03310）
- **是什么**：终身机器人学习 benchmark。Robosuite+PDDL 程序化生成 130 任务（Spatial/Object/**Goal**/100 含 **Long**），每任务 50 条人类示范。关键发现：语言嵌入退化成 Task-ID（BERT≈任务编号）——"VLA 不懂语义"的干净早期证据。
- **对 idea**：`.bddl` 的 `(:goal ...)` 谓词 = 免费可验证的目标标签（A2G 起点）；LIBERO-Goal 天然构造"同视觉、不同目标"对照；LIBERO-Long 是长时程主场。**坑**：BDDL 的 conjunct 不按时间排序——必须 replay 轨迹追踪谓词何时稳定成立；动作是 delta EEF（OSC_POSE），与 π0.5 绝对 pose 不一致，接入前核对数据配置；"注意力好看 ≠ 理解"，评测要用行为/符号级可证伪指标。

### Motus — 世界模型竞品（清华朱军组等，arXiv:2512.13030）
- **是什么**：三专家 MoT（Wan2.2-5B 生成 + Qwen3-VL-2B 理解(冻结) + 动作专家）+ UniDiffuser 式双 flow timestep，一个网络切换 VLA/WM/IDM/VGM/联合 5 模式；隐动作=光流压 14 维当"像素级 delta"；联合预测 87.0 > 纯 VLA 83.9。
- **对 idea**：验证了"累计视觉 delta 可行"与"辅助预测目标反哺策略（+3%，温和）"；Action-Dense/Video-Sparse 粗时间栅格是"语义步"聚合的现成方案。**差异**：它的语言永远是冻结条件、理解 grounding 在未来像素——"动作→语言意图"是其结构性空白。

### LingBot-VA — 最强成功率竞品（蚂蚁 Robbyant，RSS'26，arXiv:2601.21998）
- **是什么**：因果自回归视频-动作交错世界模型（MoT 5.3B，16K 小时 / 1.4T token）。RoboTwin 92.9 / LIBERO 98.5 近饱和 SOTA；KV-cache 长程记忆，长时程增益最大（H=3 时 +8~9%）。
- **对 idea**：①把"成功率已饱和、别硬碰"钉死，评测轴必须换语义/理解；②其"记忆"是视觉状态记忆（记得发生过什么），我们做语义意图理解（理解为了什么），必须在文中切开；③它的交错序列里动作是一等 token（信息可外流）——反衬 π0.5 需改造，也是 future work 的更优架构候选。

### FastWAM — 关键工程范式（清华 IIIS+银河通用，arXiv:2603.16666）
- **是什么**：拆解 WAM 收益来源：**去掉测试时未来想象几乎不掉分，去掉训练时视频协同暴跌**（真机 91→10）→ 价值在训练时塑造表征。190ms 实时、快 4×。
- **对 idea**：①"**训练时协同、推理时可裁剪**"= A2FI 头的黄金模板（加理解目标不拖慢控制）；②三组 token + 结构化 mask 是防泄漏改造样板；③警示：显式推理对成功率未必必要，必须用理解/泛化/效率指标立论；④风险：视频是稠密监督、意图是稀疏信号，塑造表征的力度可能不够（H1 有真实失败风险）。

## 2. 直接对标（已下载全文，决定差异化成败）

| 论文 | 一句话 | 与 idea 的关系 |
|---|---|---|
| **LACY** (arXiv:2511.02239, ICRA'26) | 单模型 L2A+A2L+循环一致性，A2L 自生成扩数据；短程 pick-place | **最近亲**。禁止再讲"首次双向动作-语言"；必须做 A2L(描述级) vs A2FI(意图级) 对照 (H4) |
| **ProprioCaption** (arXiv:2512.20876) | 图像+本体感觉 caption，局部合并成整轨迹目的总结（仅 22 条轨迹、GPT-4V 零样本） | 触及"轨迹目的总结"但无结构化真值/控制反馈；我们须更结构化、可验证 |
| **CoT-VLA** (arXiv:2503.22020, CVPR'25) | 当前图像+指令→想象未来帧→动作（前向视觉 CoT） | 方向相反（前向规划 vs 反向理解），一句话即可划界；其延迟与 OOD 劣化提醒别预设测试时生成意图有益 |

## 3. 2026 年最新近邻（在线核对，塑造了 07-21 重新评估）

| 工作 | 已覆盖 | 对 idea 的结论 |
|---|---|---|
| **Anchor-Align** (arXiv:2607.13429, 07-15) | 动作 chunk→方向词，同观测语言-动作联合训练 + 冻结 VLM anchoring，改善 OOD/控制；乱标签对照会退化 | **最大直接威胁 + 最佳实现模板**；必做 L1 baseline，且要证明 L2/L3 在长窗口有额外价值 |
| **WLA** (arXiv:2606.05979) | 下一状态含 textual intention + 物理 dynamics | "语义世界模型"命名已被占；方向是前向（状态→下一子任务） |
| **IntentVLA** (arXiv:2605.14712) | 视觉历史→short-horizon intent 表征 + AliasBench | intent 是隐式历史表征，非"动作→显式语义目标"；歧义定义必须比它严格 |
| **DSWAM** (arXiv:2607.04927) | System2 从视觉历史预测下一子任务 | 前向规划，进一步压缩"长时程+语言子任务"叙事 |
| **RoboSemanticBench** (arXiv:2606.02277) | 诊断 VLA 语义 grounding：抓取成功但选语义正确块近随机 | **动机证据**（非竞品） |
| **RMBench** (arXiv:2603.01229) | 记忆依赖操作 benchmark | 后期长时程平台候选 |
| **IntentionVLA** (arXiv:2510.07778) / **ThinkAct** (arXiv:2507.16815) / **ECoT** (arXiv:2407.08693) | 人类意图→动作 / 前向 latent planning / 前向语言 CoT | 方向均与 A2FI 相反或正交，related work 划界即可 |
